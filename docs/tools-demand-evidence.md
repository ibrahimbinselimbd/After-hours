# Why these 20 tools

The new tools target English-language, international users and common browser workflows across all ten existing tool districts. Selection favored tasks that have visible real-world use, established competitors or ecosystem signals, and can be implemented locally without paid APIs or a backend. None duplicates the existing background remover, image optimizer, QR generator, HEIC-to-JPG converter, or passport-photo studio.

## What the evidence does—and does not—say

The strongest exact search figures found are **Ahrefs estimates for the United States**, not global counts: its free-tools case study reports an estimated 84,000 monthly US searches for “color palette generator” and 7,000 for “contrast checker.” Ahrefs also estimates Coolors receives 340,519 US organic visits per month and its contrast-checker page 6,640. These figures are useful signs of demand, but they are third-party estimates, not audited Google totals or a forecast for AFTERHOURS. The incumbent products are strong, so a basic copy would not stand out.

Other evidence below is explicitly labeled as usage claims, open-source activity, package downloads, standards, or official guidance. GitHub stars, npm downloads, product ratings, and a vendor’s upload count are **not** interchangeable with unique users or search volume. Google says Trends provides a sampled, normalized view of search interest by region and time; it is suitable for directional comparison, not absolute monthly volume. No global search-volume total is asserted for any tool.

## Daily-credit behavior

The 20 new tools reuse the existing `afterhours:daily-credits` browser-local counter and the same `{day, remaining}` record used by Image Size Optimizer, QR Code Generator, and Passport & Visa Photo Studio. Those tools all cap the shared pool at 10 successful actions per local calendar day; the new tools add no separate allowance. HEIC → JPG keeps its already-existing independent IndexedDB counter and is not changed. This is local browser storage, not an account-wide or server-enforced quota.
